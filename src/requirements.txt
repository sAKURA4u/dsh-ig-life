# The unofficial transport's only dependency.
#
# instagrapi speaks Instagram's private API. It is a moving target: when
# Instagram changes its signing, this package has to catch up, and until it
# does the sidecar cannot log in. That is the maintenance cost of this path.
#
#   python -m pip install -r src/requirements.txt
#
# 3.x is required. Instagram stopped sending the password-encryption key
# headers that 2.x reads in password_publickeys(), so password login dies on
# int(None) there; 3.x has the same call but at least ships with current API
# fixes. The sessionid login (recommended, and the settings page supports it)
# avoids that flow entirely.
instagrapi>=3.2,<4
